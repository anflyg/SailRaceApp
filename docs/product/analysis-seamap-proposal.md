# Geographic basemap proposal for TackWise Analysis

**Status: proposal; privacy, security, CRA/GDPR and product approval pending.** This does not authorize real-race requests, a production flag, merge or deployment. It proposes a nautical map instead of the previously suggested default satellite imagery in [TackWise Analysis](tackwise-analysis.md); that product direction remains unchanged until approved.

Use MapLibre GL JS (BSD-3-Clause) with the published [Open Waters Seamap style](https://tiles.openwaters.io/seamap/style.json). The companion Analysis implementation limits external requests to synthetic tracks and retains its SVG for private races and failures. Route, replay and position are local GeoJSON, never requests or URL parameters. No API or owner authorization change is proposed. Private detail remains in memory, scoped to the signed-in owner, and is removed on race/session change.

## Sources, attribution and limitations

The [Seamap documentation](https://openwaters.io/charts/seamap/) identifies OpenStreetMap (ODbL), Seascape bathymetry, VersaTiles base data, Noto fonts (SIL OFL) and chart symbols used with permission. Hosted Seamap tiles, style and sprites are CC BY 4.0, requiring © Open Waters: Seamap; OSM requires © OpenStreetMap contributors. MapLibre's expanded attribution control must retain all attribution supplied by style and TileJSON, including Mapterhorn and Seascape and their linked source terms. Confirm all downstream licenses and display at release, as provider resources may change. The style package is MIT; the tile pipeline is GPL-3.0; neither is bundled as application code. See [Seamap source and license](https://github.com/openwatersio/seamap) and [Seascape source](https://github.com/openwatersio/seascape).

This is **not for navigation**: seamarks can be missing, outdated or incorrect, and bathymetry is not reduced to chart datum or adjusted for tides. Official nautical charts remain necessary. Coverage, accuracy, availability, fair use, costs and service guarantees need review. Fallback is schematic, not geographically authoritative.

## Data flow and release gates

A style/TileJSON inspection on 2026-11-17 found `tiles.openwaters.io` (style, seamark and Seascape TileJSON/tiles, glyphs and chart sprites) and `tiles.versatiles.org` (base vector/elevation tiles and base sprites). Attribution links point to other sites only if opened by a user. Reinspect the live style, TileJSON, redirects and actual browser traffic before release; mutable upstream resources may change. Restrict CSP `connect-src` and `img-src` to these hosts and `worker-src` to self for the bundled MapLibre worker. Reject unapproved map resource hosts and do not send cross-origin credentials. Map requests contain no GPS arrays, identifiers or tokens, but tile coordinates/zoom and timing disclose the displayed region, and network providers receive IP addresses and normal request metadata; repeated navigation may reveal a sailing area. Referrer policy must remain no-referrer. Browser caches and provider logs can retain this information beyond the in-memory track lifecycle.

Before enabling real races: approve necessity and proportionality, lawful basis and notices, provider roles/terms and sub-processors, international transfers, retention and caching, security and CRA/GDPR assessments, dependency/license and availability review, and a documented activation decision. Review CSP, endpoint redirects and network traces using synthetic data; verify no credentials or track payloads leave the browser. Verify fallback, attribution, accessibility and map behavior at target viewport sizes. Review shared-device exposure and deletion/export consequences. Synthetic browsing also discloses IP and its viewport. No approval is implied by this proposal.
