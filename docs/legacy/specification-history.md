# Legacy Specification History

The original **Specifikation Seglingsapp.docx** was the initial concept specification for the sailing application. It described the early four-phase concept: course setup, start timer, race display and post-race analysis/replay.

The product has since evolved into the TackWise suite with separate TackWise Race, TackWise Watch, TackWise Analysis and cloud services.

The original document is therefore **historical reference only** and is superseded by the current documentation under `docs/` in this repository.

Useful concepts from the original specification have been migrated into the current product documentation. Historical documents must not override accepted current product, architecture, security or privacy decisions.
