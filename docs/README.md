# TackWise documentation

This directory is the authoritative source for current TackWise product, architecture, security and privacy documentation.

## Structure

- `product/` - what TackWise Race, Watch and Analysis are intended to do.
- `architecture/` - how the system is designed and how components interact.
- `security/` - security-by-design and CRA-related evidence and processes.
- `privacy/` - GDPR, data minimisation, retention and privacy-by-design.
- `legacy/` - historical documents and migration notes only.

Existing operational documents such as sensor notes, manuals and TestFlight checklists remain valid where they do not conflict with current product or architecture decisions.

When documentation conflicts, use this precedence:
1. Accepted architecture/design decision.
2. Current files under `docs/product`, `docs/architecture`, `docs/security`, `docs/privacy`.
3. Operational/manual documentation.
4. Historical/legacy specifications.
