# Security and CRA

TackWise security documentation is maintained incrementally as part of development.

The goal is proportionate security-by-design and evidence suitable for a small software product, including preparation for applicable EU Cyber Resilience Act obligations.

Current working documents:
- `cra-risk-assessment.md`
- `threat-model.md`
- `vulnerability-policy.md`
- `incident-response.md`

These documents are initial stubs and must evolve with the product.
